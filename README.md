# Zig Bindings for Godot (GDExtension)

WIP Zig bindings for the Godot game engine, built directly on top of
Godot GDExtension C ABI.

## What this is

Godot exposes its native extension interface as a C API (`gdextension_interface.h`)
plus a machine readable API description (`extension_api.json`). This project uses
that data to generate and hand write Zig bindings that let Zig code talk to Godot
across the FFI boundary without going through C++.

## Why this is interesting technically

Working at the C ABI boundary means dealing directly with raw pointers, manual
memory management, and matching Zig type system to Godot binary layout with
no C++ helper layer in between. This is the layer that would normally be hidden
by `godot-cpp`.

## Structure

- `zig/` binding code
- `extension_api.json` Godot's API description (input, not generated by this repo)
- `gdextension_interface.h` Godot's C ABI header (vendored, not authored here)

## Status

Personal project, not production-ready. Built to explore FFI/C ABI interop
between Zig and a large existing C/C++ codebase (Godot Engine).
